# CP31 Solutions
My solutions to selected problems of the [CP31 sheet](https://www.tle-eliminators.com/cp-sheet) by TLE Eliminators.

## Format
Most directories have a structure as follows, 
```
.
├── [problem].cpp           // solution to the problem
├── README.md               // Problem statement, constraints, and sample I/O
└── SOLUTION.md             // write-up with approach, code and submission link
```
